# Source and validation notes

The dataset is UniTools World Recipes version 2.0.0, published under CC BY-SA 4.0 by UniTools — theunitools.com. The exact source file hash, access date, selection rule and 36 slugs are in `data/source_manifest_v4.json`. It is a published external collection; the available dataset documentation does not establish that every selected recipe has been personally cooked or independently checked. The dataset's own tags, times and instructions are not medical, allergy or food-safety certification.

The selection retains every selected source ingredient, amount, unit, scaling label and English note, plus English instructions and source times. Steps are numbered and source per-step durations annotated; images and nutrition are omitted. The data is adapted and attributed under the same CC BY-SA licence. The source dataset's individual recipe pages are retired; the dataset landing page is retained for provenance.

Automated checks found 36 recipes, 378 ingredient entries, 36 unspecified quantities and 20 generated evaluation cases. They also checked required fields, unique names/slugs, servings, ingredient types and scaling rules. The original downloaded JSON was checked against `ingest_source_v4.normalize`; it produced the exact saved selection. This is a consistency check, not human recipe verification. A basic keyword check did not find obvious meat/fish terms in recipes marked vegetarian/vegan; it is not exhaustive and cannot verify labels, allergens, additives, product variants or cross-contact.

`results/retrieval_check_v4_20261125_181052_905300.json` records a local test on 13 questions whose labelled evidence is mostly tied to an explicitly named recipe. The expected recipe section appeared in the top five for 13/13 questions, but ranked first for 7/13. This is not a Ragas precision/recall/faithfulness score and does not prove the answer will be correct. The dataset and 20 reference cases need independent review. At the time of this initial check there had been no live Groq or Ragas evaluation; later tests and their limitations are documented separately in `QWEN_EVALUATION_v1.md`.

The source uses `linear`, `fixed` and `damped` scaling labels. The program scales linear ingredients, keeps numerical fixed ingredients, and leaves damped or unspecified amounts for manual adjustment, because this dataset file does not define a damped formula. Automated tests exercise the real MCP process and the graph path using a test model; production model routing and argument extraction remain unverified for this corpus.
