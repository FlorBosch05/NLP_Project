# Qwen evaluation of sourced recipes

The saved live answer run `results/evaluation_qwen_v1_sections_k5_20261125_191925.json` uses `qwen/qwen3.8-27b`, section chunking and top-k 5 on the 20 source-derived V4 cases. All 20 routes and all six expected MCP results matched. The generator reported 22,837 input and 3,342 output tokens, 26,179 total; judge use is separate.

The two scaled answers used correct tool quantities and flagged damped ingredients, but the Ratatouille answer also repeated source instructions containing original amounts. This can confuse scaled amounts. The separately versioned `chef/agent_scale_v2.py` and `app_scale_v2.py` format the tool output without presenting unscaled steps as scaled; the offline fake-model/real-MCP test `test_scale_v2.py` passed. This is a separate candidate, not the agent used to generate the saved live answer run, and requires live retesting.

The live Miso soup time answer exposed a source inconsistency: its overview says the soup takes ten minutes, while the structured source fields list five minutes of preparation and fifteen minutes of cooking. Qwen reported both and noted the discrepancy. The original source fields were preserved; the correct time has not been independently established.

The Ragas run `results/ragas_qwen_v1_20261125_192005_072400.json` scores the 13 retrieval cases from that saved answer run with Qwen as judge. Six cases completed with all three metrics; Q07 produced no usable metrics because Groq returned daily-token-limit errors, and Q08–Q13 were not attempted. The separate partial summary `results/ragas_summary_qwen_v1_20261125_192854_419300.json` reports means over those six cases only: context precision 0.714, context recall 1.000 and faithfulness 0.962. They are not a full 13-case benchmark and are susceptible to selection bias. Retry starting at `--offset 6 --limit 7` after sufficient quota is available; the failed Q07 must be retried. Each attempt saves a new file.

The judge callback reported 67,358 tokens across the seven attempted cases, including 516 reported on the failed Q07. This is in addition to the 26,179 reported generation tokens. These figures may not capture failed or unreported calls and are not a statement of billable tokens or remaining quota. Ragas results do not assess the scaling presentation bug. The recipe content and test references are publisher-derived and not independently reviewed. Using Qwen for both generation and judging can introduce bias. Do not mix these results with V3 or different judges.
